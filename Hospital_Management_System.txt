+------------+---------------+--------------+
5 rows in set (0.012 sec)

REASON:
SUM adds each patient's invoice amounts. GROUP BY creates one group per patient. HAVING filters grouped totals. ORDER BY sorts totals from largest to smallest. LIMIT returns only five rows.

Q4(c). Show paid revenue by department.
ANSWER:
SELECT dep.department_name,
       COALESCE(SUM(CASE WHEN b.payment_status = 'Paid' THEN b.amount ELSE 0 END), 0) AS paid_revenue
FROM Departments dep
LEFT JOIN Doctor_Department dd ON dd.department_id = dep.department_id
LEFT JOIN Doctors d ON d.doctor_id = dd.doctor_id
LEFT JOIN Appointments a ON a.doctor_id = d.doctor_id
LEFT JOIN Billing b ON b.appointment_id = a.appointment_id
GROUP BY dep.department_id, dep.department_name
ORDER BY paid_revenue DESC, dep.department_name;

OUTPUT ::
+------------------+--------------+
| department_name  | paid_revenue |
+------------------+--------------+
| Cardiology       |      9200.00 |
| Emergency        |      6000.00 |
| Orthopedics      |      3900.00 |
| Dermatology      |      2000.00 |
| Neurology        |      1800.00 |
| General Medicine |         0.00 |
| Pediatrics       |         0.00 |
+------------------+--------------+
7 rows in set (0.009 sec)

REASON:
The joins connect departments to doctors, appointments and invoices. CASE counts only Paid invoices; COALESCE turns NULL totals into zero. A doctor assigned to multiple departments can contribute revenue to each department, so these department totals should not be added together as a unique hospital total.

Q8(b). Identify patient(s) who spent the most on non-cancelled invoices.
ANSWER:
SELECT p.patient_id, p.name, totals.total_spent
FROM Patients p
JOIN (
    SELECT patient_id, SUM(amount) AS total_spent
    FROM Billing
    WHERE payment_status <> 'Cancelled'
    GROUP BY patient_id
) totals ON totals.patient_id = p.patient_id
WHERE totals.total_spent = (
    SELECT MAX(patient_total)
    FROM (
        SELECT SUM(amount) AS patient_total
        FROM Billing
        WHERE payment_status <> 'Cancelled'
        GROUP BY patient_id
    ) x
);

OUTPUT ::
+------------+------------+-------------+
| patient_id | name       | total_spent |
+------------+------------+-------------+
|          2 | Diya Patel |     3400.00 |
+------------+------------+-------------+
1 row in set (0.023 sec)

REASON:
The first subquery calculates spending per patient. The inner MAX subquery finds the largest patient total. The outer query returns patient(s) whose total equals that maximum. Cancelled invoices are excluded, while Pending invoices are included.

Q11(a). Rank doctors by number of patients treated.
ANSWER:
WITH doctor_patient_counts AS (
    SELECT d.doctor_id, d.name,
           COUNT(DISTINCT CASE WHEN a.status = 'Completed' THEN a.patient_id END) AS patients_treated
    FROM Doctors d
    LEFT JOIN Appointments a ON a.doctor_id = d.doctor_id
    GROUP BY d.doctor_id, d.name
)
SELECT doctor_id, name, patients_treated,
       RANK() OVER (ORDER BY patients_treated DESC) AS patient_rank
FROM doctor_patient_counts
ORDER BY patient_rank, name;
